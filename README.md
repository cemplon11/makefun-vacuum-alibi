One line, at most 200 characters, in which a robot vacuum explains why it missed a spot.

## The line

> Dust detected under the sofa at 04:12. By 04:13, we had reached an understanding. I left.

## How it works

`main.py` is pure Python standard library. It deterministically writes the line above to `/output/entry.txt` — no network, no randomness, no third-party packages.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
